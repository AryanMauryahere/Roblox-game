# Raccoon City Courier ☣️

A survival horror Roblox game inspired by the 2026 Resident Evil adaptation. Built with custom Luau server-client mechanics, claustrophobic environmental lighting, and realistic civilian gunplay.

## 🌟 Key Features
- **Atmospheric Horror Engine:** Dynamic volumetric fog capped at 40 studs, dark midnight lighting, and camera-attached blizzard particle systems.
- **Inaccurate Civilian Shooting:** Over-the-shoulder camera with heavy, movement-influenced weapon sway.
- **Resource Scarcity:** 4-round pistol capacity with 4 spare rounds and a custom 5.5-second fumbling reload animation.
- **AI Integration:** Programmed and debugged using GPT-6 Astra via Ropilot Studio.

## 📁 Repository Structure
- `Raccoon City Courier.rbxlx`: Main Roblox Studio XML place file containing all game architecture, UI, lighting, and scripts.
- `.gitignore`: Configured to exclude temporary Roblox lock files (`*.rbxlx.lock`).

## 🛠️ Built With
- **Roblox Studio** (Luau)
- **Ropilot Studio** (GPT-6 Astra engine)
